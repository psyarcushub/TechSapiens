# TechSapiens: стартап, который собирает вся конференция

Это репозиторий игры: участники конференции присылают идеи стартапа, ИИ-агент Гермес выбирает одну и прямо во время докладов собирает из неё работающий прототип. Каждый принятый промпт и каждый pull request превращаются в новую версию продукта, а на странице «О стартапе» видно, из чьих идей он вырос.

- Продукт: https://techsapiens.vercel.app
- Канал игры, где выходят все версии: https://t.me/techsapiensproject
- Бот для идей и промптов: https://t.me/TechSapiens_bot

## Как участвовать

1. **Идея.** В начале игры отправьте боту идею стартапа. Гермес сгруппирует похожие идеи и выберет одну.
2. **Промпт.** Когда откроется сборка, отправьте боту, что добавить или изменить в продукте. После модерации промпт попадёт в ближайшую пачку, и Гермес соберёт новую версию.
3. **Код.** Если вы пишете на TypeScript и React, пришлите pull request с собственной функцией. Как это сделать, написано в [CONTRIBUTING.md](CONTRIBUTING.md).

Смешные идеи приветствуются, если продукт после них открывается и не ломается.

## Как это устроено

Сайт статический: Vite, React 19, TypeScript, Tailwind 4, компоненты shadcn/ui, иконки lucide-react и Material Symbols, шрифт Tilda Sans, оформление в стиле TechSapiens. Никаких серверов, баз и запросов в интернет, данные живут в браузере.

Каждая функция продукта лежит в своей папке `src/features/<id>/` и подхватывается сама. Если одна функция упадёт, вместо неё появится заглушка, а остальное продолжит работать. Перед выкладкой каждая версия проходит проверку типов, сборку и прогон в настоящем браузере по всем экранам; не прошедшая проверку версия на сайт не попадает.

```bash
npm install
npm run dev     # локальный сервер для разработки
npm run check   # типы, сборка и прогон в браузере
```

Правила для агента и для всех, кто пишет код: [AGENTS.md](AGENTS.md).
